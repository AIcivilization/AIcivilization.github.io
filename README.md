- [dsh-vps-manager](https://github.com/AIcivilization/dsh-vps-manager) — 在 DeepSeek Harness 里管理你的 VPS

纯静态单页（`index.html` + `assets/`），无构建步骤；中英文随浏览器语言，右上角可切换。
